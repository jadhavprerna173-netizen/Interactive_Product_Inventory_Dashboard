# Interactive Product Inventory & Analytics Dashboard

## Project overview
A beginner-friendly JavaScript web application for adding, validating, searching, categorizing, and analyzing products.

## Requirements
- A modern browser (Chrome, Edge, or Firefox)
- No installation or internet connection is required to run the project

## How to run
1. Extract the ZIP file.
2. Open the `index.html` file.
3. The dashboard opens in your web browser.
4. Add products, search the inventory, delete items, and use the tax/discount calculator.

## Features
- Product data stored as an array of objects
- Explicit input conversion with `Number()`
- `if...else` validation and price categories
- `switch` statement for category descriptions
- Loops, `continue`, and `break` for inventory searching
- Regular functions and arrow functions
- Local variables and scope
- Total inventory value, average price, premium count
- Tax and discount calculation
- Safe display of user-entered product names

## Price category rules
- Budget: price up to ₹500
- Standard: price above ₹500 and up to ₹2,000
- Premium: price above ₹2,000

## Core JavaScript concepts demonstrated
1. Variables and constants: `let`, `const`
2. Data types and conversion: `Number()`, strings, numbers
3. Arrays and objects: `inventory`
4. Conditions: `if`, `else if`, `else`
5. `switch` statement
6. Loops and flow control: `for`, `continue`, `break`
7. Functions and arrow functions
8. Scope: local variables inside functions
9. Array methods: `push`, `filter`, `reduce`, `map`
10. DOM interaction and event listeners

## Sample initial inventory
- Notebook — ₹80 — Budget
- Water Bottle — ₹350 — Budget
- Keyboard — ₹1,200 — Standard
- Headphones — ₹2,500 — Premium

## Important note
The application keeps data in memory while the page is open. Refreshing the page restores the sample inventory; products are not permanently saved.
